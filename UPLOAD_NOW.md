### STEP 1: Create GitHub Repository (2 minutes)

1. Open: https://github.com/new
2. Repository name: `library-management-system`
3. **Don't** check any boxes (no README, no .gitignore)
4. Click **"Create repository"**
5. **Copy** the repository URL shown

### STEP 2: Connect Your Code (1 minute)

**Open PowerShell/Command Prompt in your project folder and run:**

```bash
git remote add origin https://github.com/YOUR_USERNAME/library-management-system.git
```

*(Replace YOUR_USERNAME with your GitHub username)*

### STEP 3: Push to GitHub (1 minute)

```bash
git branch -M main
git push -u origin main
```

**Enter your GitHub username and password/token when prompted**
